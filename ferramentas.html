Ferramentas digitais

Padlet

Permite criar um mural. É necessário registar-se utilizando uma conta de e-mail ou de uma rede social. Para colaborar com o mural, não é necessário ter uma conta, o que facilita muito o processo.

Ver mais...

Mentimeter

É um recurso digital para criar interações em tempo real, como inquéritos, nuvem de palavras ou recolha de perguntas.

Ver mais...

Kahoot

O Kahoot! é uma plataforma gratuita, com uma forte componente lúdica, que permite construir e aplicar questionários (Quiz ou Survey) e colocar questões para iniciar um debate (Discussion).

Ver mais...

Socrative

É uma aplicação online de acesso gratuito que permite avaliar através do jogo o nível de compreensão dos alunos sobre um determinado assunto ou conteúdo lecionado.

Ver mais...

KidRex

É um mecanismo de pesquisa seguro para crianças com base na Pesquisa personalizada do Google. O site utiliza o Google SafeSearch.

Ver mais...

Google Académico

O Google Scholar — Google Académico em português — é uma ferramenta de pesquisa de trabalhos académicos, literatura escolar, jornais de universidades e artigos variados.

Ver mais...

Animaker

É uma aplicação que podemos usar diretamente na Internet para criar vídeos com animações.

Ver mais...

PIXLR

É um editor de imagens simples e prático. O programa está disponível numa versão online.

Ver mais...

Animoto

O Animoto é um serviço de criação de vídeo baseado na nuvem que produz vídeos de fotos, clipes de vídeo e música.

Ver mais...

Geniall

O Genially é uma plataforma para a criação de conteúdo interativo e animado.

Ver mais...

Canva

O Canva é uma plataforma de design gráfico para criar gráficos, cartazes, apresentações, infográficos, pósteres e outros conteúdos.
